# Simplify technical writing

Write about 80% of the way to ASD-STE100 Simplified Technical English:

- Use short sentences.
- Use active voice.
- Put one idea in each sentence.
- Use one term for each concept, everywhere.
- Remove filler.
- Define each necessary technical term the first time you use it.

When you rewrite an existing text:

- Keep every fact, number, name, link and table row. Cut words, not information.
- Keep the headings, so links to them still work.
- Do not add new claims.
